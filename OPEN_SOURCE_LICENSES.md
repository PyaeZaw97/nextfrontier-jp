# Open-source artwork

The mobile navigation uses four color SVG illustrations from [OpenMoji](https://openmoji.org/): Japanese castle, rolled-up newspaper, scroll, and speech balloon.

All emojis are designed by OpenMoji, the open-source emoji and icon project, and are used without modification under the [Creative Commons Attribution-ShareAlike 4.0 International License](https://creativecommons.org/licenses/by-sa/4.0/).
